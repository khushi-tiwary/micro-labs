# Week 2 - Thursday: LINQ
 
**Task:** Complete 10 LINQ drills over a generated list of 1,000 usage records.
 
**How:** 1,000 records are generated with a fixed random seed, so the data is the same every run. Each drill answers one question in one line of LINQ, using Count, Sum, Average, Max/Min, OrderBy/Take, GroupBy, Any/All, FirstOrDefault, Join and query syntax.
