# Week 06 - Middleware in ASP.NET Core

## Overview

Demonstrates built-in and custom middleware implementation in ASP.NET Core Web API.

## Concepts Covered
- Middleware Pipeline
- HTTPS Redirection
- Custom Request Logging Middleware
- RequestDelegate and HttpContext
- Controller Routing

## Technologies
- C#
- ASP.NET Core Web API
- .NET

## Run the Project
`  bash`
`dotnet restore`
`dotnet run`

 ## Learning Outcome

Understanding middleware execution, custom middleware creation, and HTTP request processing in ASP.NET Core.
